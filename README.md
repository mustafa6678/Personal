# ThePhoneShopExpress - Modern Technical Studio Platform

A premium, manufacturer-style web platform for **ThePhoneShopExpress**, Preston. Built with Next.js 15, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Manufacturer-Grade UI:** A sleek, high-contrast design mirroring official tech stores (Apple/Samsung style).
- **Comprehensive Service Hub:** Detailed repair sections for Smartphones, Consoles, and Laptops.
- **Certified Shop:** A product-focused gallery for refurbished flagship devices.
- **Smart Inquiry System:** Integrated server-side email functionality with branded notifications.
- **Responsive Engineering:** Fully optimized for mobile, tablet, and desktop viewports.
- **High-Performance:** Built with Next.js App Router and optimized for SEO.

## 🛠️ Technology Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Vanilla CSS
- **Animations:** Framer Motion
- **Iconography:** Lucide React
- **Backend:** Next.js Server Actions + Nodemailer

## 📦 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/[your-username]/thephoneshopexpress.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Configure Environment Variables:**
    Create a `.env.local` file and add your SMTP credentials (see `.env.example`).
4.  **Run locally:**
    ```bash
    npm run dev
    ```
